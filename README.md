# Анализ TCP-трафика с помощью Python, Scapy и Wireshark

## Описание проекта

Учебный проект, демонстрирующий передачу текстового сообщения через TCP на локальный сервис, захват сетевого трафика и анализ пакетов с помощью Wireshark.

Проект создан для практического изучения сетевых протоколов, принципов TCP-соединения и методов анализа сетевого трафика.

## Цели проекта

* Установить TCP-соединение с локальным сервисом.
* Отправить заданное текстовое сообщение с помощью Python и Scapy.
* Захватить сетевой трафик через loopback-интерфейс.
* Изучить заголовки TCP-пакетов и полезную нагрузку (payload).
* Сохранить захваченный трафик в формате PCAPNG.
* Проверить корректность переданного сообщения.

## Используемые инструменты и технологии

* **Python 3** — реализация отправителя и локального TCP-сервера.
* **Scapy** — работа с сетевыми пакетами.
* **TCP/IP** — протоколы сетевого взаимодействия.
* **Wireshark** — захват и визуальный анализ трафика.
* **Npcap** — захват сетевого трафика в Windows.
* **TShark** — дополнительная проверка дампа из командной строки.

## Установка и запуск

### 1. Установка зависимостей

Установить необходимые библиотеки:

```bash
python -m pip install -r requirements.txt
```

### 2. Запуск TCP-сервера

В первом терминале выполнить:

```bash
python src/server.py
```

Сервер ожидает входящее TCP-соединение на `127.0.0.1:12345`.

### 3. Настройка захвата трафика

Открыть Wireshark и выбрать интерфейс `Adapter for loopback traffic capture`.

Для ограничения захватываемого трафика использовать capture filter:

```text
tcp port 12345
```

### 4. Отправка сообщения

Во втором терминале выполнить:

```bash
python src/send_message.py
```

### 5. Анализ пакетов

Для отображения TCP-пакетов с полезной нагрузкой использовать display filter:

```text
tcp.port == 12345 && tcp.len > 0
```

Проверить адреса, порты, TCP-флаги и содержимое полезной нагрузки.

### 6. Сохранение дампа

Сохранить захваченный трафик в файл:

`src/sent_message.pcapng`
